# The $12 Key Card

A one-liner for the Make.fun one-liner marathon.

> My hotel key card died four times in one night. The front desk reissued it, apologised, and charged me $12 for the inconvenience of their magnet.

## How it works

`main.ts` is a dependency-free Node 22 program. Run it with `node main.ts` and it writes the joke — exactly 145 characters, one line, no trailing newline — to `/output/entry.txt`, then exits.
